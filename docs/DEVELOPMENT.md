# Arch Monitor: где что лежит

## Запуск и сборка из репозитория

На Arch Linux установи зависимости, затем запускай команды из корня репозитория:

```bash
sudo pacman -S --needed python-pyqt6 python-psutil qt6-svg
python3 -m archmon
```

Самораспаковывающийся установщик собирается стандартной библиотекой Python:

```bash
python3 build_installer.py
bash -n install-archmon.sh
```

Результат — `install-archmon.sh` в корне репозитория. В архив входят приложение,
тесты, документация и лицензия. После изменения исходников пересобери установщик,
чтобы его содержимое соответствовало файлам репозитория.

Все проверки, включая изолированную установку и удаление:

```bash
ARCHMON_INSTALLER="$PWD/install-archmon.sh" QT_QPA_PLATFORM=offscreen \
  python3 -m unittest discover -s tests -v
```

Тесты используют временные каталоги и подставные процессы, службы и датчики.
Они не меняют реальные настройки вентиляторов. Снимок в README сделан из самого
интерфейса на демонстрационных данных; это не замер производительности.

## Установленные файлы

Файлы после установки находятся в `~/.local/share/archmon/archmon/`. Это обычные `.py`:
поправил, закрыл и снова открыл приложение, и изменения применились (пересобирать ничего не нужно).

| Хочу…                                              | Правлю                         |
|----------------------------------------------------|--------------------------------|
| сменить интервал обновления, размер окна, трей     | `config.py`                    |
| пункты бокового меню (порядок, подписи, значки)    | `window.py` → `NAV_ITEMS` |
| размеры колец на главной                           | `config.py` (`RING_SIZE`, `CORE_RING_SIZE` …) |
| диски: что показывать, какие разделы пропускать    | `disks.py` (чтение, без Qt; `SKIP_FSTYPES`, `SKIP_PREFIXES`) + `disks_page.py` (страница) |
| вентиляторы платы: поиск, драйвер, страница Fans   | `fans.py` (чтение, без Qt) + `fans_page.py` (страница) |
| кривые вентиляторов, пресеты, защита (мин. скорость, аварийные 100 %) | `fand.py` (служба, работает от root) |
| как служба ставится в систему (systemd, pkexec, polkit) | `fan_service.py` + `fanctl.py` (помощник от root) |
| добавить свою цветовую тему или поменять цвета     | `theme.py` (строка `Theme(...)`) |
| значок в трее: иконка, меню, подсказка             | `tray.py`                      |
| окно сведений о процессе                           | `details.py` (поля в `FIELDS`) |
| кнопка Reflector (обновить зеркала pacman)         | `reflector.py` (команда, сведения о зеркалах) + `reflector_button.py` (кнопка) |
| настройки MangoHud: галочки, пресеты, запуск, логи | `mangohud.py` (логика, список опций `FLAGS`, `PRESETS`) + `mangohud_dialog.py` (окно) |
| режим дерева процессов (свёртка и раскрытие веток) | `tree.py` (порядок и видимость), `window.py` (`_group_rows`, `toggle_node`) |
| что считать приложением, а что системным           | `classify.py` (правила) и `config.py` (`FORCE_APPS`, `FORCE_SYSTEM`, `APP_PATH_PREFIXES`) |
| изменить пороги жёлтого и красного на полосах      | `config.py` (`WARN_AT`, `CRIT_AT`) |
| добавить, убрать, переименовать колонку таблицы    | `columns.py`                   |
| поменять правила подсветки ячеек таблицы           | `window.py` → `_cell_color()`  |
| изменить внешний вид кнопок, полей, прокрутки      | `style.py` (цвета берутся из темы) |
| изменить вид полосы или карточки видеокарты        | `widgets.py`                   |
| добавить показатель в карточку видеокарты          | `gpu.py` (поле `Gpu` и чтение) + `widgets.py` (`GpuCard`) |
| поддержать другую видеокарту / источник данных     | `gpu.py`: новая `_read_xxx()` и строка в `read_gpus()` |
| добавить данные о системе (диск, сеть…)            | `system.py` (чтение) + `window.py` (`_build_system_card`, `update_system`) |
| поменять горячие клавиши                           | `window.py` → `_setup_shortcuts()` |
| добавить или изменить плашки внизу (они кликабельны) | `window.py` → `_build_footer()` |

## Как устроено

    config.py   настройки              columns.py  колонки таблицы
    theme.py    цветовые темы          style.py    стили (QSS)
    helpers.py  мелкие функции         classify.py приложения и системные процессы (без Qt)
    tree.py     порядок строк в режиме дерева (без Qt)
    system.py   данные: CPU, память, температуры, процессы (без Qt)
    gpu.py      данные: видеокарты (без Qt)
    gpu_poll.py фоновый опрос GPU (Qt); один запрос за раз, повтор при временном сбое
    widgets.py  Ring (кольцо), Meter (полоса), GpuCard, кнопки меню и подсказок
    details.py  окно сведений о процессе    tray.py     значок в трее
    single.py   защита от второго запуска
    mangohud.py / mangohud_dialog.py   управление MangoHud (логика без Qt и окно)
    reflector.py / reflector_button.py   обновление зеркал pacman (логика без Qt; кнопка и страница)
    disks.py / disks_page.py             диски, разделы, скорости (чтение без Qt и страница)
    fans.py / fans_page.py               вентиляторы материнской платы (чтение без Qt и страница)
    fand.py / fan_service.py             служба кривых вентиляторов и её установка
    window.py   главное окно          app.py      запуск

Модули `system.py` и `gpu.py` не знают про интерфейс, их можно проверить в терминале:

    cd ~/.local/share/archmon
    python3 -c "from archmon import gpu; print(gpu.read_gpus())"

Запуск из терминала с выводом ошибок: `cd ~/.local/share/archmon && python3 -m archmon`

## Полезное

- В режиме Tree ветки сначала свёрнуты: стрелка ▸ (клик по ней или клавиша →) раскрывает, ▾ (или ←) сворачивает; у свёрнутой ветки видно число скрытых процессов. Кнопки Expand all и Collapse all, поиск (F3) сам раскрывает нужные ветки, а при фильтре дерево раскрыто целиком.
- Тема и режим дерева запоминаются между запусками (файл `~/.config/archmon/archmon.conf`).
- `archmon --hidden` запускает программу сразу в трее. Для автозапуска положи ярлык в `~/.config/autostart/`.
- Зажатый Ctrl замораживает окно (как в диспетчере задач Windows): список не двигается, можно спокойно выбрать строку. Логика в `window.py` → `_poll_freeze()`.
- После поиска найденная строка держится на месте при обновлении списка, пока ты не покрутишь колесо, не потянешь ползунок или не кликнешь по строке (`_search_lock` в `window.py`).
- Кнопка «Apps first» выводит выше программы, которыми пользуешься (Firefox, Konsole, игры), а ниже системные процессы; запоминается между запусками. В режиме дерева группы тоже работают: у каждой своё дерево.
- Окно разбито на разделы в боковом меню: Overview (кольца и процессы), Processes (только таблица), GPU, Disks, Fans, MangoHud, Reflector, Settings. Тема по умолчанию Graphite.
- Кнопка в разделе Reflector перезапускает reflector.service через pkexec (система спросит пароль). Пока reflector работает, кнопка неактивна; результат пишется внизу окна, а если окно в трее, приходит уведомление. Подсказка на кнопке показывает, сколько зеркал в списке и когда он обновлялся.
- Программа запускается в одном экземпляре: повторный запуск просто показывает уже открытое окно (`single.py`).
- Крестик окна прячет программу в трей. Совсем закрыть: F10, Ctrl+Q или «Quit» в меню трея.
  Чтобы крестик закрывал программу, поставь `CLOSE_TO_TRAY = False` в `config.py`.

## Служба вентиляторов

- Первый «Apply» на странице Fans (и первый после обновления) спрашивает пароль и ставит в систему службу `fand.py`, помощник `fanctl` в `/usr/local/lib/archmon/`, юнит `archmon-fans.service` и правило polkit `/etc/polkit-1/rules.d/50-archmon-fans.rules`. Дальше «Apply» и «Back to BIOS» идут через `fanctl` без пароля (для группы wheel). `fanctl` принимает только настройки вентиляторов и проверяет каждое поле. Служба стартует при каждой загрузке.
- Журнал службы: `journalctl -u archmon-fans`. Выключить с проверкой восстановления: кнопка «Back to BIOS» или `pkexec /usr/local/lib/archmon/fanctl stop`.
- В BIOS ничего не записывается. Служба возвращает режимы, которые были до её запуска. Если до запуска уже было ручное управление, восстановится именно оно.
- При ошибке восстановления исходное состояние остаётся в `/run/archmon-fans/original.json`, чтобы повторить попытку. Программа не сообщает об успехе до подтверждения восстановления.
- `bash install-archmon.sh --remove` останавливает и отключает службу, проверяет восстановление, затем удаляет её файлы и правило polkit. При ошибке удаление прерывается, файлы сохраняются.

## Проверки и изменения

Список исправлений и команды запуска проверок находятся в [CHANGES.md](../CHANGES.md). Проверки используют подставные процессы и оборудование. Установщик не меняет BIOS и не загружает драйверы автоматически.
