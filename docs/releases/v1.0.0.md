Первый релиз Arch Monitor — монитора системы для Arch Linux с интерфейсом на PyQt6.

### Возможности

- Мониторинг CPU, памяти, GPU, дисков и процессов.
- Управление вентиляторами платы, настройка MangoHud и запуск Reflector.
- Шесть тем, системный трей, поиск и дерево процессов.

### Исправления и оформление

- Защита от завершения другого процесса при повторном использовании PID.
- Опрос GPU в отдельном потоке и восстановление показаний после временной недоступности.
- Проверка возврата исходных режимов вентиляторов при остановке службы и удалении.
- Исправления настроек MangoHud и статистики CSV-логов.
- Обновлённые README, логотипы и документация.
- GNU GPL v3.0 (GPL-3.0-only). Полный текст лицензии включён в установщик.

### Установка и обновление

Скачайте `install-archmon.sh` из раздела **Assets**, откройте терминал в папке со скачанным файлом и выполните:

```bash
bash install-archmon.sh
~/.local/bin/archmon
```

Повторный запуск установщика обновляет приложение. Для удаления:

```bash
bash install-archmon.sh --remove
```
