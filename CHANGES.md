# Исправления от 15 ноября 2026

- Выбор процесса хранит PID и время создания. Если процесс исчез из таблицы или PID занят новым процессом, выбор сбрасывается. Завершение проверяет выбранную строку и идентичность процесса.
- Опрос GPU выполняется в отдельном потоке, без наложения запросов. При выходе приложение дожидается завершения текущего ограниченного по времени опроса.
- GPU появляется в интерфейсе при первом успешном опросе, даже если запуск прошёл без данных. Временная потеря данных обозначается как недоступность; повторный опрос восстанавливает показания автоматически.
- Отсутствующее значение занятой видеопамяти показывается прочерком.
- Служба вентиляторов сохраняет список каналов, которым нужно вернуть исходные режимы, до включения ручного управления. Ошибки восстановления повторяются и не выдаются за успех. При перегреве и невозможности сменить режим служба также пытается выставить максимальную скорость.
- Перед сменой конфигурации служба останавливается и проверяет восстановление прежних каналов. Невосстановленное состояние сохраняется для повторной попытки.
- Удаление останавливает и отключает службу, проверяет возврат исходных режимов, затем удаляет системные компоненты и правило polkit. Ошибка восстановления прерывает удаление с сохранением файлов. Если служба не устанавливалась, удаление остаётся пользовательским.
- Установщик проверяет целостность встроенного архива до установки или удаления.
- MangoHud сохраняет явное отключение управляемых флагов. Нулевой интервал логирования поддерживается как запись каждого кадра.
- CSV отображает количество замеров, а длительность — по колонке elapsed в наносекундах. Без пригодных временных отметок длительность считается неизвестной. Среднее и минимумы подписаны как показатели выборки, без обещания точного анализа всех кадров.
- Некорректные числовые настройки MangoHud заменяются в интерфейсе значениями по умолчанию с пояснением. Сам файл изменяется только по нажатию Save.
- Подсказка для Gigabyte начинает с определения чипа; отключение проверки конфликтов ACPI больше не предлагается как обязательная настройка.

Внешний вид, разделы, темы, трей, дерево процессов и остальные функции сохранены. Новых зависимостей приложения нет: Python, PyQt6, psutil и QtSvg остаются прежними.

## Проверка

Встроенные проверки выполняются из каталога приложения:

```bash
cd ~/.local/share/archmon
QT_QPA_PLATFORM=offscreen python3 -m unittest discover -s tests -v
```

Проверки используют временные файлы и подставные процессы, службы, датчики и команды. Проверка установщика дополнительно запускается при заданном `ARCHMON_INSTALLER`, указывающем на скачанный `.sh`. Она перенаправляет файловые операции в временный каталог и подменяет системные команды.

Проверки на настоящей материнской плате, с реальным polkit и сессией KDE/Wayland не заменяются этими тестами. Изменения BIOS и драйверов установщик не выполняет.
